# 第二阶段识别改进

用户要求分析并提高第二阶段识别正确率，保留第二阶段检测、分割、视觉大模型的同图比较。

已经核对：第一阶段88.84%对应1183张官方测试；在旧共同120张上是97/120=80.83%，第二阶段88/120=73.33%。第二阶段15张检测漏掉，17张检测后分类错误。第一阶段在漏检的15张上认对12张。两个阶段训练和验证数量相同，但随机划分不同，不能把模型差异全部解释为模型结构差异。

方案选择（开发决定）：先用238张验证集做旧分类器原图/主体消融；新分类器使用官方通用ImageNet预训练Swin-Tiny，独立微调，保留YOLO26n和SAM2辅助主体定位。猫品种头与猫/狗头共享Transformer特征。猫训练原图仍为950张；狗只从官方trainval取训练负例，验证负例独立保留，不接触官方test。检测失败时原图照常送分类器；由单独训练的物种头判断猫是否存在。该负例训练覆盖狗，不能把其验证成绩写成所有非猫图的通用性能。

原图与主体分支、水平翻转平均由验证集选择；最终只输出一个品种。测试图不参与训练、调参或选模。旧120张已公开诊断，保留为回归集；另从其余官方test提前固定每类10张的新共同集，用作本次冻结后的独立比较。旧图和新图分别报告；对旧版整1183和同题120的数字明确标注分母。

下载、训练、验证、推理共用ModelTask锁，串行运行；下载失败不重试。训练batch8、workers0、CPU线程2，每批同步后等待0.05秒。独立推理batch1，验证最多batch2并等待0.2秒。训练每轮在原图验证上选择检查点，结束后一次验证选融合配置。完整日志和旧数据、权重、要求、视频都保留；不上传仓库或发微信。

训练实现支持轮次检查点，异常直接退出；只有用户要求继续后才允许人工恢复。保留旧版完整交付包，新版另存，不覆盖旧记录。界面与报告同步真实结果，失败计入分母。
