验收要求

1. 仓库与历史
GitHub / Gitee持续提交；代码与依赖说明统一入库。
保留真实开发历史，避免完成后一次性上传。

2. 一份文档说明
介绍项目与个人感悟；自由撰写，不限定字数或格式。

3. 一个运行视频
运行项目，展示主要结果；不限定时长。

4. 参考与创新
参考教程和参考项目仅作为参考，不推荐直接提交参考项目；
鼓励自行拓展学习，创新项目。

5. AI辅助开发
鼓励使用AI；理解代码，能够修改与排查问题。
