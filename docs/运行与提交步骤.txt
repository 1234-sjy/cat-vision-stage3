怎么运行、怎么提交

一、在当前电脑验收

浏览器打开 http://127.0.0.1:8765 。选择一张猫照片，点“开始识别”，等待两条路线分别完成。每边只显示一个品种。下面的案例按钮展示历史运行结果；选好案例后再点“开始识别”，会重新实际运行。

项目服务停止后，打开PowerShell，在项目目录执行：
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/start.ps1 -PythonExe 你的Python环境中的python.exe路径

Python解释器由运行环境指定。项目不需要开发者的用户名目录，也不需要把虚拟环境整包复制过去。

二、换一台电脑运行

1. 解压完整保留包，进入其中的“项目”文件夹。
2. 安装Python 3.12，安装时勾选加入PATH。完整的双路线实时推理需要NVIDIA CUDA显卡，建议16GB显存。
3. 双击“安装环境.cmd”，等待依赖安装完成。
4. 双击“启动项目.cmd”，保持窗口开着。
5. 在浏览器打开 http://127.0.0.1:8765 ，选图运行。

完整保留包内已经有模型权重和数据，通常不用重新下载或训练。只有源码时，先恢复依赖，再运行：
python scripts/download_models.py --only all
其中自训练的weights/breed-best.pt约11MB，已随源码保留；该命令用于获取官方通用模型。下载中断或校验失败时保留日志，先检查原因，不要设置自动重启循环。

需要精确恢复开发版本时，在已选定的环境内执行：
python -m pip install -r requirements-lock.txt
这份文件已把本机wheel路径改为版本号和官方CUDA安装来源；原始pip freeze另外保存在artifacts/environment供核对。

三、代码仓库怎么上传

第二阶段PDF允许GitHub或Gitee。使用你或帮忙同学能正常使用的账号，新建一个空仓库，名称可用cat-vision-stage2。先不要勾选README、.gitignore或许可证模板。

把cat-vision-stage2-source.bundle发给帮忙上传的同学。这个文件保留了真实Git历史、源码、项目文档、课程要求提要、实验记录和自训练分类权重。请对方安装Git，把bundle放进一个文件夹，在该文件夹打开终端，依次执行：

git clone .\cat-vision-stage2-source.bundle cat-vision-stage2
cd cat-vision-stage2
git branch -M main

接着，把下方REPOSITORY_URL替换成刚建好的仓库HTTPS地址，再执行：

git remote set-url origin REPOSITORY_URL
git push -u origin main

clone bundle后已有origin，所以这里用set-url。登录由上传者在自己的电脑完成。上传后打开仓库网页，确认有README、catvision、scripts、docs、artifacts，以及weights/breed-best.pt，再把新仓库链接发回。

第二阶段是独立项目，使用第二阶段的新仓库链接。第一阶段的旧链接继续对应第一阶段。

四、发什么、发到哪里、给谁

把第二阶段新仓库链接、项目说明PDF和实际运行视频，发给考核群指定的第二阶段验收学长或收件人。PDF没有写出具体姓名，收件人以群公告或学长通知为准。

可以直接复制这段话，再填入链接：
“学长好，这是我的第二阶段项目‘看图识猫’。同一组图片分别通过检测分割加品种分类、视觉大模型两条路线处理，文档和视频里有实际结果。代码仓库：在这里粘贴第二阶段仓库链接。附件是项目说明和运行视频。”

五、几个文件分别有什么用

项目说明与实现感悟.pdf：交给验收者阅读，包含方法、真实指标、案例与实现感悟。
实际运行演示.mp4：交给验收者看运行过程。
cat-vision-stage2-source.bundle：给帮忙上传代码的人，保留Git历史，不直接当作仓库链接。
完整成果与保留数据.zip：自己留存或交接。它保留PDF、完整课程提要、原始视频、数据、所有模型与下载历史、训练记录和源码。

完整保留包体积较大。验收者需要全部模型和数据时，可以把它存到网盘后发送下载链接。按PDF先交仓库链接、文档和运行视频；不要把整个保留包的几十GB文件直接上传代码仓库。
